   · Генерируется при создании бота или мини-приложения.
   · Отображается как: API Токен: <значение>.
   · Назначение: "Сохраните этот токен - он нужен для подключения".
2. 📥 PHP SDK
   · Прямая ссылка на скачивание: pubtalk_sdk.php.
   · Описание: "Готовый PHP-класс для входа через PubTalk на вашем сайте. Поддерживает: вход по логину, проверку токена, получение профиля, NFT, чатов, баланса ⭐, отправку сообщений, звёзд и push-уведомлений."
3. 🔐 Готовая страница входа
   · Ссылка на скачивание: login.html.
